# 3D 资产清单

流程：codex-imagegen 生成白底参考图 → 确认 → Tripo 图生 3D → Blender MCP 归一化、减面、LOD、烘焙顶点色、写入部位属性 → glTF（meshopt）放入 `web/public/models/`。

风格：低多边形建筑沙盘，平涂着色、可见多边形切面、无贴图，颜色贴合 [ui-design.md](ui-design.md) 的色板。

文件位置：参考图与 Tripo 原始输出放在 `~/Assets/WildfireTwinLA/`（大文件不进 git），处理后的 glTF 才进仓库。

## 参考图统一要求

所有参考图都满足以下条件，便于 Tripo 图生 3D：

- 单个物体，三分之四视角，略俯视约 20°，物体完整、居中、四周留白
- 纯白背景 `#FFFFFF`，柔和均匀的棚拍光，无投影、无地面、无其他物体、无文字
- 低多边形沙盘风格，可见切面，哑光纯色，无贴图、无描边
- 植被用偏灰的 chaparral 绿与鼠尾草绿，不用饱和绿
- 房屋的屋顶在造型上与墙体明确分开（Blender 中拆为两个部位，燃尽时屋顶消失）
- 第一张（海岸活橡树）作为风格基准，其余各张以它为参考图（`-r`）保持风格一致

## 处理结果

- **加纳利海枣已移除**：Tripo 输出的树干藏在下垂叶丛中，无法区分树干与树冠；街道棕榈由墨西哥扇棕代表。
- **输电塔与配电杆程序化建模**（`tools/assets/build_props.py`）：细杆结构不适合图生 3D。导线挂点写在节点 extras 的 `wire_points` 中（glTF 坐标，Y 向上）。
- **房屋 LOD1 程序化生成**：自动减面到几十个面会塌成碎片，改为按 LOD0 生成墙体方块加屋顶（四坡或平顶）。
- **房屋高度单独校正**：Tripo 生成的房屋长高比与真实不符，按长边缩放后再把高度校正到目标值。

## 导出格式（`web/public/models/<name>.glb`）

| 项 | 内容 |
|---|---|
| 节点 | `<name>_LOD0`（近景）、`<name>_LOD1`（中景），都在原点 |
| 坐标 | 米制，Y 向上，原点在底部中心 |
| 顶点属性 | `POSITION`、`NORMAL`、`COLOR_0`（逐面纯色，线性空间）、`_PART`（0 = 树冠/屋顶，燃尽时消失；1 = 树干/墙体） |
| 着色 | 平直着色（每个面独立顶点），无贴图 |
| 面数 | 树 LOD0 500–900、LOD1 80–140；房屋 LOD0 500–600、LOD1 20–24；输电塔 1712 / 640；配电杆 156 / 32 |

重建全部资产：

```bash
/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup --python tools/assets/build_all.py
```
